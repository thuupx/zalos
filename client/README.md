# zalos

Flutter client for zalos. Cryptography (Noise transport, vault) lives in the
Rust crate under `rust/` and is called through flutter_rust_bridge 2.12.0;
the generated Dart bindings are in `lib/src/rust_lib/`.

## Build

### Prerequisites

- Flutter (see `environment` in `pubspec.yaml`) and a Rust toolchain via
  `rustup`.
- Native builds compile the Rust crate automatically through the
  `rust_builder/` plugin (cargokit, generated by
  `flutter_rust_bridge_codegen integrate` 2.12.0). Cargokit runs
  `rustup target add` for any missing target of the platform being built
  (e.g. `aarch64-apple-ios-sim`, `aarch64-linux-android`).
- Android also needs the Android SDK and NDK; Windows and Linux builds must
  run on that host OS.
- On Apple Silicon, Flutter release (AOT) builds need Rosetta 2
  (`softwareupdate --install-rosetta`).

### Native

```sh
flutter pub get
flutter build macos --debug     # or --release, ios, apk, windows, linux
```

No manual copying of the Rust library is needed: on macOS and iOS it is
linked into `rust_lib_zalos.framework`, on Android, Windows and Linux it is
bundled as `librust_lib_zalos` / `rust_lib_zalos.dll`.

After changing the Rust API, regenerate the bindings:

```sh
flutter_rust_bridge_codegen generate
```

### Web

Build the flutter_rust_bridge wasm bundle (`web/pkg/`) first, then the web
app:

```sh
../scripts/build-noise-web.sh
flutter build web --release
```

### macOS signing

Both Debug and Release are ad-hoc signed ("Sign to Run Locally",
`CODE_SIGN_IDENTITY = "-"`) so they build without an Apple Developer team.
For that reason `macos/Runner/Release.entitlements` does not request
`keychain-access-groups`: that entitlement must be backed by a provisioning
profile from a paid team. flutter_secure_storage only needs it for the data
protection keychain; without it secrets are stored in the user's login
keychain, which works for local and unsigned distribution. To ship a
notarised build, set a development team in Xcode, add
`keychain-access-groups` back and enable the data protection keychain in
`lib/src/data/key_store.dart`.
